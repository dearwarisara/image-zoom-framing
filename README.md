# Frame — Local Image Framing

เว็บจัดเฟรมภาพแบบไม่เรียก OpenAI API และไม่ส่งภาพออกจากเบราว์เซอร์ ประมวลผลด้วย Canvas ของเครื่องผู้ใช้

## สิ่งที่ทำได้

- Zoom in: ขยายภาพและครอปบริเวณกึ่งกลาง
- Zoom out: ย่อภาพและเติมพื้นที่รอบนอกด้วยพื้นหลังเบลอจากภาพต้นฉบับ
- Resize และเปลี่ยนแนวภาพ: ขยายกรอบตามสัดส่วนที่เลือก โดยคงภาพต้นฉบับไว้ด้านหน้า
- ส่งออกผลลัพธ์เป็น PNG

การเติมฉากเป็นการประมาณด้วยสีและรายละเอียดเบลอจากภาพเดิม ไม่ได้สร้างฉากใหม่ด้วย AI หรือใช้ภาพอ้างอิง

## เปิดใช้ในเครื่อง

ใช้ Node.js 20 ขึ้นไป:

```bash
npm run dev
```

จากนั้นเปิด `http://localhost:3000` ไม่มี API key หรือการตั้งค่า billing ที่ต้องใช้

## Deploy

เว็บไซต์ production ใช้ Codex Sites Worker ที่ `worker/index.js` และ Site จำกัดสิทธิ์ผู้เข้าชมตามการตั้งค่าของบัญชี ภาพทั้งหมดประมวลผลในเบราว์เซอร์ของผู้ใช้

GitHub repository เก็บ source code เท่านั้น และไม่ได้เปิด GitHub Pages
